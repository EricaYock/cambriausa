# columns-moodboard

Custom **columns** block. Purpose: Design moodboard pairing a surface with complementary slabs, paint colours and hardware.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells. Each image (optionally followed by a caption paragraph, optionally containing one link) becomes a tile. A list item or paragraph containing a hex colour (e.g. **Mocha Cream** / Benjamin Moore / #d3c9bd) becomes a round swatch..

## Supported variations

No variations.
