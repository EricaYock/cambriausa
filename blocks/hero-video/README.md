# hero-video

Custom **hero** block. Purpose: Top-of-page banner over a muted, looping background video.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1: poster image and a link to the video file (.mp4/.webm). Row 2: optional logo image, heading, optional text, one or two CTA links.

## Supported variations

No variations.
