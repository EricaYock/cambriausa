# carousel-gallery

Custom **carousel** block. Purpose: Product image gallery showing one image (or video poster) at a time.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide, image cell only; a video slide holds its poster image plus a link to the .mp4 (optional text becomes a caption).

## Supported variations

No variations.
