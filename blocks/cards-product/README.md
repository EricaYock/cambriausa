# cards-product

Custom **cards** block. Purpose: Commerce product listing grid with an optional promo tile.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile: image cell, then a text cell. Product: optional badge paragraph ('New'), vendor paragraph, linked product name, price paragraph. Promo: bold title paragraph (or heading) and a CTA link.

No variations.
